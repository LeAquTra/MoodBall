  • 🔋 省电：缩略图静态图 + 背景/波纹/柔光全关 — 适合插在 Raspberry Pi/Orange Pi 这种低性能板子上，稳定 60fps。
  • ⚖️ 平衡（默认）：缩略图静态图 + 背景静止 + inset 柔光 — 特效不抢 SDK 的弹簧帧，主流笔记本/手机稳定丝滑。
  • ✨ 丝滑：开启星河双层漂移 + 径向混叠柔光，特效拉满 — 适合独显/高性能 PC，拍视频/演示用。
